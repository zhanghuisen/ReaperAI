============================================
ReaperAI v1.0.7 - 安装与使用说明
============================================

【推荐安装方式】

1. 从 GitHub Releases 下载 ReaperAI-Setup-v1.0.7.exe。
2. 完全关闭 REAPER，然后运行安装程序。
3. 选择包含 reaper.exe 的 REAPER 根目录。
   支持 C、D、F、S 等任意盘符，也支持带空格和括号的自定义路径。
4. 安装完成后启动 REAPER，按 ? 打开 Action List。
5. 搜索 ReaperAI 并运行。

不要点击 GitHub 的 Code -> Download ZIP 进行安装；该压缩包是开发源码。
用户不需要安装 Python，也不需要运行 BAT。安装包已经内置全部核心依赖和 FFmpeg。

============================================

【首次配置】

1. 在 ReaperAI 设置页选择 LLM Provider。
2. 填写对应服务商的 API Key。
3. 选择或输入模型名称。
4. 点击“测试连接”，确认 API 可用后保存。

============================================

【卸载】

在 Windows“设置 -> 应用 -> 已安装的应用”中找到 ReaperAI 并卸载。
卸载器会先询问是否保留用户配置，再要求确认是否卸载 ReaperAI。
选择保留时会保留 API、模型、音频服务、MCP 配置和音色缓存；选择不保留时会一并删除。

============================================

【注意事项】

- 安装核心组件不需要联网，调用 LLM 或音频服务时需要网络。
- 安装和卸载前请关闭 REAPER。
- 默认 MCP 端口为 8765。
- 如果 Windows 显示 SmartScreen 提示，请先核对 GitHub Release 公布的 SHA256。

GitHub: https://github.com/zhanghuisen/ReaperAI
